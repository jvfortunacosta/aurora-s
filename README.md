# Aurora's Cleaning Services | Site institucional

Site institucional para uma empresa de limpeza residencial e pós-obra que atende **Massachusetts e Rhode Island (EUA)**. Todo o conteúdo é em inglês e o foco é gerar pedidos de orçamento pelo WhatsApp e por mensagem.

🔗 **Demo:** [aurora-s.vercel.app](https://aurora-s.vercel.app)

## Destaques

- Hero com chamada direta para orçamento
- Seção de serviços (limpeza regular, pós-mudança e pós-obra)
- **Comparador de antes e depois** interativo
- Depoimentos, FAQ e formulário de orçamento
- SEO on-page (title, meta description e estrutura semântica)
- Layout responsivo e animações de entrada ao rolar a página

## Stack

HTML5, CSS3 e JavaScript puro, com deploy na Vercel.
